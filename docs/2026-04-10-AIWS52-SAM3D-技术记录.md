## 4. 批处理脚本技术规格

脚本：`scripts/run_sam3d_aiws52_batch.py`

### 4.1 输入参数（关键）

- `--dataset-root`：数据集根目录
- `--dataset-layout`：`subset`（本项目正式配置）
- `--repo-root`：SAM3D 仓库目录
- `--output-root`：当前 shard 输出目录
- `--resume`：跳过已存在 `mesh.glb` + `mesh.stl` 的任务
- `--num-shards` / `--shard-index`：并行分片参数
- `--exclude-stems-file`：可选排除名单

### 4.2 单任务数据流

每个任务包含：

1. 读取 RGB 图像
2. 读取 annotation JSON
3. 从 polygon 栅格化得到二值 mask
4. 调用 `Inference(image, mask, seed)`
5. 导出 `mesh.glb` 与 `mesh.stl`
6. 写入实例级 `meta.json` 与全局 `results.jsonl`

### 4.3 分片策略

任务按 `global_index % num_shards == shard_index` 分配。

在 4 卡模式下：

- shard 0: `% 4 == 0`
- shard 1: `% 4 == 1`
- shard 2: `% 4 == 2`
- shard 3: `% 4 == 3`

保证：

- 不重复
- 不漏跑
- 可独立追踪每个 shard

### 4.4 产物与指标

每个 shard 产物：

- `manifest.csv`
- `results.jsonl`
- `summary.json`
- 每实例输出目录（含 `mesh.glb`、`mesh.stl`、`meta.json`）

关键指标：

- `duration_sec`
- `instances_per_hour`
- `sec_per_megapixel`
- `mask_pixels` / `mask_fraction`
- `peak_memory_allocated_mb` / `peak_memory_reserved_mb`
- `gpu_name`
- `num_shards` / `shard_index`

### 4.5 失败与恢复语义

- 失败任务会写入 `meta.json`（含错误类型、错误信息、traceback）
- 中间临时文件（`mesh.partial.*`）失败后自动清理
- `--resume` 可直接断点续跑

## 6. `flash_attn` 在 RTX A6000 上的启用

### 6.1 问题一：预编译 wheel 二进制不兼容

- 预编译 wheel 依赖更高 glibc
- 服务器环境不满足

处理：服务器本地源码编译 `flash_attn`。

### 6.2 问题二：默认后端选择不会覆盖到 A6000

即使 import 成功，仓库默认后端选择也不会自动切到 A6000。

处理：显式设置环境变量：

- `ATTN_BACKEND=flash_attn`
- `SPARSE_ATTN_BACKEND=flash_attn`

### 6.3 最终状态

正式运行中 dense/sparse attention 均使用 `flash_attn`，日志可见后端信息。

## 7. 运行手册（Runbook）

### 7.1 启动单个 shard（示例）

```bash
ATTN_BACKEND=flash_attn \
SPARSE_ATTN_BACKEND=flash_attn \
CUDA_VISIBLE_DEVICES=0 \
/home/rxl/anaconda3/envs/sam3d-objects/bin/python -u \
/ssd1/rxl/zhankaiming/AIWS/scripts/run_sam3d_aiws52_batch.py \
  --dataset-root /ssd1/rxl/zhankaiming/AIWS/data/aiws5.2-usable-materialized \
  --dataset-layout subset \
  --repo-root /ssd1/rxl/zhankaiming/AIWS/repos/sam-3d-objects \
  --output-root /ssd1/rxl/zhankaiming/AIWS/outputs/sam3d-aiws52-clean-mesh-stl-20260410-193527/shard-0 \
  --resume \
  --num-shards 4 \
  --shard-index 0
```

### 7.2 监控 4 个 shard 汇总

```bash
for s in /ssd1/rxl/zhankaiming/AIWS/outputs/sam3d-aiws52-clean-mesh-stl-20260410-193527/shard-*; do
  echo "--- ${s} ---"
  jq '{completed_ok, failed, skipped, processed, total_tasks_in_shard, eta_sec}' "${s}/summary.json"
done
```

### 7.3 断点续跑

保留原参数并继续带 `--resume` 重启相应 shard 即可。
